# 🐍 Snake Game Web

A classic **Snake Game** built for the web using **HTML, CSS, and JavaScript**.

The project recreates the classic Snake experience with a clean interface, responsive controls, and simple game mechanics.

## 🎮 Features

* 🐍 Classic Snake gameplay
* 🎯 Food collection system
* 📈 Score tracking
* 💀 Game-over detection
* 🔄 Restart functionality
* ⌨️ Keyboard controls
* 📱 Responsive design
* ⚡ Lightweight and fast

## 🎮 How to Play

1. Start the game.
2. Use the **Arrow Keys** to control the snake.
3. Eat the food to increase your score.
4. Avoid hitting the walls.
5. Avoid hitting your own body.
6. Try to achieve the highest score possible! 🏆

## 🚀 Running the Game

Clone the repository:

```bash
git clone https://github.com/asteralvoidwalker/snake-game-web.git
```

Open the project folder and launch:

```text
index.html
```

You can also use the **Live Server** extension in VS Code for a better development experience.
